# 학생 관리 만료확인일 검증 메모

2026-08-27 관리자 학생 관리 화면에서 월 원비 합계 카드에 `만료확인일 30일 이내` 명단이 표시되는 것을 확인했다. 천지은 5일, 이채원 6일, 김예진 10일을 포함해 11명의 재원 학생이 남은 기간 오름차순으로 표시됐다. 운영 데이터는 조회하지 않고 변경하지 않았다.

이지은2 학생의 정보 수정 팝업에서 기존 `학생 번호` 위치가 `학교명`으로 표시되고 기존 값 `강서고`가 보존되는 것을 확인했다. 총 수업 횟수를 228회에서 229회로 입력만 변경했을 때, 저장하지 않고도 만료확인일이 2027-01-01에서 2026-10-26으로 즉시 갱신됐다. 이는 2026-08-27 한국 시간 기준 60일 뒤이며, 팝업은 취소로 닫아 운영 데이터를 변경하지 않는다.
