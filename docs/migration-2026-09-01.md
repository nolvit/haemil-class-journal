# 2026-09-01 전체 백업 이전 순서

1. 새 MySQL 호환 데이터베이스를 생성한다.
2. 백업의 `database/haemil_class_journal_full.sql`을 가져온다.
3. 이 프로젝트의 `drizzle/0015_parent-pwa-attendance.sql`을 적용한다.
4. 백업 이미지의 원래 `imageKey` 경로를 `UPLOAD_DIR` 아래에 복원한다.
5. `.env.example`의 필수 환경변수를 새 값으로 설정한다.
6. 기존 백업에 노출된 DB 비밀번호, JWT 키, Forge 키와 임시 Git 토큰을 폐기한다.
7. 관리자 로그인, 보호자 링크, 알림 구독, 총 횟수 알림, 등원·하원 입력을 차례로 검증한다.

기존 학생의 출결번호는 마이그레이션에서 학생 ID에 1000을 더한 4자리 값으로 최초 부여된다. 신규 학생은 중복되지 않는 임의의 4자리 번호를 받는다.
