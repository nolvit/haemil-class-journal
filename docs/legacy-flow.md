# 기존 수업일지 이식 기준

첨부된 기존 프로젝트는 **업무 날짜를 고른 뒤 출석을 입력하고, 과목별 수업일지를 작성한 다음, 누락·불일치를 확인하는 순서**로 운영된다. 새 웹앱도 이 핵심 동선을 대시보드의 `출석 입력 → 수업일지 작성 → 미입력 확인` 순서로 유지한다.

| 기존 사용 방식 | 새 웹앱의 이식 방식 |
|---|---|
| 일자별 운영 업무판 | 날짜 선택이 가능한 업무 현황 대시보드 |
| 학생별 출석 상태와 등원 시간 입력 | 출석 관리 화면의 학생별 상태 선택 및 등원 시간 저장 |
| 과목별·학생별 수업 내용의 인라인 입력 | 반별 수업일지 목록과 학생별 편집 대화상자 |
| 수업 내용 및 학생별 비고 | 수업 내용, 과제, 특이사항의 분리된 기록 필드 |
| 미입력·누락 항목 확인 | 노란색 카드, 미입력 필드 배지, 미입력 전용 필터 |
| 보호자별 학생 수업일지 열람 | 학생별 비공개 토큰 링크 기반 주간 열람 화면 |

수업일지 완성 조건은 출석 대상 학생의 **출석 상태, 수업 내용, 과제** 입력이다. 결석·미등록 학생은 수업일지 작성 제외로 표시하여 실제 기존 운영 규칙을 반영한다. 특이사항은 선택 입력이며, 강사와 관리자는 로그인 기반으로 기록을 확인하고 수정한다. 강사는 본인이 최초 작성한 기록을 수정할 수 있고, 관리자는 모든 기록을 관리할 수 있다.
