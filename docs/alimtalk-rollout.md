# 알림톡 템플릿 연동 확인

## 발송 원칙

- PWA 알림은 변경하지 않는다.
- 알림톡은 templateId와 variables로 발송한다. 강조 제목·본문·고정 버튼은 솔라피 템플릿에서 관리한다.
- 요청에 text, subject, imageId 또는 buttons를 중복 지정하지 않는다.
- disableSms: false로 대체발송을 허용한다. 콘솔에서 저장한 짧은 문자 및 MMS 이미지 적용 여부는 실제 시험 발송으로 확인해야 한다.
- 이미지첨부형이 아닌 강조표기형이다. 알림톡 이미지 ID를 별도로 추가하지 않는다.

## 등록비 안내 링크

사용자가 접속 확인한 주소: https://www.haemiledu.kr/tuition

첫 번째 템플릿의 `등록비 안내 보기` 웹링크 버튼에 모바일·PC 모두 위 주소를 사용한다.
고정 링크이므로 발송 변수에 URL을 추가하지 않는다. 템플릿 콘솔의 실제 저장값은 시험 전에 확인한다.

## 변수와 환경변수

| 용도 | 템플릿 ID 환경변수 | 변수 |
| --- | --- | --- |
| 남은 수업 1회 안내 | SOLAPI_REMAINING_ONE_TEMPLATE_ID | 학생명, 원비안내, 결제방법 |
| 납부 후 총 횟수 변경 | SOLAPI_PAYMENT_CONFIRMED_TEMPLATE_ID | 학생명, 변경전횟수, 변경후횟수 |

변수 키는 `#{학생명}` 형식이다. 결제방법에는 조사까지 포함한다(예: 계좌이체로).
API 키·시크릿·발신번호·채널 ID·템플릿 ID 두 개가 모두 설정되어야 기존 자동 발송이 활성화된다.
시험 전에는 운영 자동 발송이 켜지지 않도록 유의한다.

## 시험 및 남은 점검

1. 두 템플릿 심사 승인과 위 링크 저장값을 확인한다.
2. 원장 번호로 각각 발송해 강조 제목·치환값·버튼 링크를 확인한다.
3. 솔라피의 대체발송 시험 방식으로 문자 내용 및 MMS 이미지를 별도 확인한다. 다른 학생에게 시험하지 않는다.
4. API 접수 성공과 최종 수신 성공을 구분한다. 현재 DB의 sent는 API 요청 성공 기록이다.
5. 총 횟수 증가가 납부 외 정정·무료 추가에도 사용되는지 검토한다. 이번 변경은 발송 조건을 바꾸지 않는다.
6. 실패 재시도·중복 방지 보완, 개인정보 위탁 안내, 노출된 API Secret 교체는 별도 작업이다.

참고: https://solapi.com/developers/sdk/nodejs-sendingexample
템플릿 구성: https://solapi.com/developers/sdk/kakaolinkguide-20260220-122755

## 관리자 시험 버튼

알림 로그 → 알림톡 시험 발송. 서버가 재원생 박서율을 유일하게 조회하며 수신번호를 입력하거나 다른 학생을 지정할 수 없다. 동명이인이 있으면 중단한다.
두 종류 중 하나를 선택하고 실제 변수와 보호자 번호를 확인한 뒤 발송한다. 아직 실제 발송 검증은 하지 않았다.
납부 확인은 현재 총 횟수 + 월 등록 횟수(주 횟수 × 4)의 가상 변경을 사용한다. 학생·수업·납부 기록과 PWA 발송에는 영향을 주지 않는다.
시험 접수 기록은 test: 접두사로 자동 발송 중복 방지 기록과 분리한다. API 접수번호를 표시하며 최종 배달 여부는 휴대폰 및 솔라피에서 확인한다.
