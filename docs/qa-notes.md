# QA 검증 기록

2026-08-26 개발 미리보기에서 관리자 로그인 상태의 업무 현황 화면을 데스크톱과 모바일 폭으로 확인했다. 따뜻한 종이 질감의 배경, 짙은 청록색 내비게이션, 노란색 미입력 강조, 날짜 기반 업무 동선이 의도대로 표시되었다.

모바일 동시 화면 캡처에서는 일부 데이터 요청 화면이 로딩 스켈레톤 단계로 저장되었다. 이는 동시 경로 캡처 중 발생한 화면 전환 상태이므로, 서버 재시작 후 각 화면을 단독으로 다시 확인한다. 단위 테스트와 프로덕션 빌드는 이 시점에 성공했다.

실제 연결 브라우저에서는 프로젝트에 로그인 세션이 없는 상태로 확인되어, 수업일지 경로는 의도한 로그인 안내 화면으로 전환되었다. 로그인 시작은 사용자 계정 인증 흐름을 여는 동작이므로 실행하지 않았다. 인증 후에는 초기 소유자 계정이 관리자 권한을 받고, 이후 사용자는 강사 권한으로 생성된다.

최신 서버 재시작 후 모바일 수업일지 화면에서 날짜 이동, 반 선택, 미입력 전용 필터와 노란색 안내가 정상 표시되었다. 빈 데이터베이스 상태에서는 수업 기록 영역이 로딩 스켈레톤을 먼저 표시하며, 실제 데이터 요청 이후에는 반·학생별 목록 또는 빈 상태로 전환하도록 구성되어 있다.

기존 SQLite 데이터에서 활성 학생 33명, 수강 연결 68건, 출석 84건, 수업일지 167건, 과목 반 5개를 새 데이터베이스에 이관했다. 이관 직후 데이터베이스 수량을 다시 확인했으며, 임시 이관 API와 원본 추출 파일은 즉시 삭제했다. 미리보기 캡처는 로그인 확인 직후의 로딩 상태를 먼저 촬영할 수 있으므로, 관리자 화면에서는 수 초 후 학생·반 데이터 요청이 완료되는 흐름을 기준으로 검증한다.

기존 파일을 재대조해 출석·수업일지를 월요일 기준 주간 입력으로 전환했고, 일요일~토요일을 함께 입력할 수 있는 선택형 주말 토글을 추가했다. 학생 관리에는 원비, 등록 횟수, 이전 주 횟수, 수업 후 횟수, 총·잔여 횟수와 결제 방식이 포함되며, 기존 33명 모두의 원비·등록 횟수 값이 이관됐다. 보호자 링크는 전용 관리자 메뉴에서 복사·열람·재발급할 수 있다.

모바일 화면에서 주간 출석 관리의 날짜 이동·주말 토글, 주간 수업일지의 반 선택·미입력 필터·날짜별 그리드, 학생 관리의 33명·월 원비 합계·확인 필요 수, 보호자 링크 전용 메뉴의 안내 문구가 모두 좁은 화면에 맞게 표시되는 것을 확인했다. 주간 수업일지는 이관된 수강 연결을 기준으로 68개의 학생·반 수업 기록을 표시했다.

기존 SQLite에서 이관한 보호자 토큰 일부가 16자보다 짧은 11~12자 형식이어서 공개 API의 토큰 길이 검증에서 거절되는 문제가 있었다. 기존 토큰을 허용하도록 최소 길이를 8자로 조정했다. 수정 후 실제 보호자 링크에서 학생명, 주간 출석 기록, 요일별 날짜와 주말 보기 토글이 정상 표시되는 것을 확인했다.

수정 배포본이 적용된 도메인에서 기존 보호자 토큰으로 공개 열람 화면이 정상 표시되는 것을 재확인했다. 모바일 화면에서는 주간 표가 가로 스크롤로 유지되며, 전체 요일 기록을 확인할 수 있도록 좌우 이동 안내를 추가했다.

기존 보호자 수업일지를 다시 대조해 공유 화면에 주간 기간, 누적 수업·등록 횟수, 이번 주 수업 횟수, 과목별 비고 열, 출석 목표 달성 안내를 복원했다. 기존 SQLite의 과목별 주간 비고 1건도 현재 수학 반에 이관했다. 모바일에서는 주간 표가 가로 스크롤로 유지되며, 요약 카드와 목표 안내가 함께 확인된다. 관리자 메뉴는 학생 관리 다음에 반 관리, 보호자 링크 순으로 표시된다.

보호자 공유 화면은 데스크톱에서 1,440px 기준의 넉넉한 표로 표시되어 가로 스크롤바 없이 전체 요일과 비고를 확인할 수 있다. 모바일에서는 표를 주간 출석 카드와 과목별 일자 기록 카드로 재구성해 가로 스크롤 없이 읽을 수 있다. 감사 문구는 `소중한 자녀를 믿고 맡겨 주셔서 감사드립니다.`로 정리했으며, 목표 안내는 별도 문장으로 표시한다. 수업일지는 과제 선택 입력, 비고 선택 입력, 과목 빠른 이동을 제공하고 반 관리는 과목만 등록하도록 간소화했다.

모바일 카드형 화면에서 기존 표 스크롤 안내를 날짜별 카드 안내로 교체했다. 과목별 카드도 데스크톱 표와 같은 기준으로 결석·미등록·출석 미입력 상태를 표시하며, 수업 기록이 없는 출석일만 `작성된 수업 내용이 없습니다.`로 안내한다.

최신 배포 도메인에서 보호자 공유 링크를 다시 열어 과목명, 감사 문구의 띄어쓰기, 주간 출석 목표 문구, 날짜별 기록과 비고가 정상 표시되는 것을 확인했다. 모바일 카드 미리보기에서는 데스크톱 표와 동일하게 결석·미등록은 상태명, 그 외 미작성 셀은 `—`로 표시되는 것을 확인했다.

배포 도메인을 실제 375×812 모바일 viewport로 대기 후 캡처해 주간 출석 카드와 과목별 기록 카드가 정상 렌더링되는 것을 확인했다. 카드형 화면에는 가로 스크롤이 없고, 날짜별 출석·미등록·미입력 상태가 데스크톱 표의 규칙과 일치한다.

실제 배포 도메인을 375×812 모바일 브라우저 DOM으로 다시 추출해 `주간 출석`, `SUBJECT` 카드 2개, `미등록`, `미입력`, `—` 상태 표현이 렌더링되는 것을 명시적으로 확인했다.

현재 주의 실제 보호자 공개 조회에서 목·금 미래 칸은 출석과 수업일지 모두 `—`로 표시되며, 이전에 표시되던 과목별 주간 비고도 숨겨지는 것을 확인했다. 당일 이전의 출석과 수업 기록은 정상적으로 표시된다.

내부 수업일지 API의 모든 조회·작성 절차를 관리자 권한으로 변경했다. 일반 로그인 계정으로 내부 대시보드를 호출하는 단위 테스트는 `FORBIDDEN`을 반환하며, 현재 관리자 계정은 `ersia85@naver.com`과 `nolvit@gmail.com` 두 명임을 확인했다. 보호자 토큰 링크는 로그인 없이 주간 출석·수업일지를 정상 공개한다.
