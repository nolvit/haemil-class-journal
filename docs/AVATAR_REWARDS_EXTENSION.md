- 학생 팝업 잔액 아래에 ‘내 포인트 적립·사용 내역 보기’를 추가했다. 관리자 조정 사유도 같은 원장에서 확인한다.
- 관리자 ‘아바타 제작’ 학생 선택 후 ‘포인트 지급·차감’에서 정수 1~100,000P를 조정한다. 사유 필수, 적용 전 잔액 확인, 담당 관리자 ID 및 요청 ID 저장. 동일 요청 재시도는 한 번만 반영한다. 보유 포인트 초과 차감은 차단한다.

- 얼굴 크롭은 상하와 좌우를 조정하고 저장한다. 기존 사진의 좌우 위치는 50(중앙)으로 유지한다.
