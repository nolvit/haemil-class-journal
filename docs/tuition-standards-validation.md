# 원비 기준표·자동 산정 검증 메모

2026-08-27 관리자 화면에서 `학원 관리 > 원비 기준` 메뉴가 반 관리와 휴강 관리 사이에 표시되는 것을 확인했다. 원비 기준 화면에는 20·16·12회 행과 초등 5과목 패키지, 중·고등 1과목 및 2과목 이상 열이 나타났으며, 제공된 등록비 표의 15개 초기 금액이 모두 원 단위로 표시됐다.

같은 관리자 화면에서 학생 등록 팝업을 저장 없이 열었다. 학년·수강 과목·등록 횟수가 아직 정해지지 않은 상태에서는 `자동 산정` 상태, 자동 산정 근거 안내, 기준 없음 안내가 표시되고 저장 버튼은 비활성화됐다.

검증용 신규 학생의 학년을 `중2`로 입력하고 영어 과목 하나를 선택했다. 등록 횟수가 아직 0회이므로 기준 없음 안내가 유지되어, 세 가지 산정 조건이 모두 필요함을 확인했다.

등록 횟수를 주 4회로 입력하자 `중학생 · 1과목 · 월 16회`, `자동 산정`, `160,000원`이 즉시 표시됐다. 이어 월 원비를 170,000원으로 직접 바꾸자 상태가 `개별 원비`로 바뀌고 산정 근거는 보존됐다. 이 과정에서는 저장을 실행하지 않았다.

`자동 산정 적용`을 누르자 상태와 원비가 각각 `자동 산정`, `160,000원`으로 복원됐다. 이후 학생 등록을 취소해 검증용 입력은 저장되지 않았고, 등록 학생 수와 기존 월 원비 합계가 각각 32명과 8,350,000원으로 유지됐다.

데스크톱 1280px 화면에서는 15개 기준 입력값과 안내 카드가 한 화면 폭에 정돈되어 표시됐다. 모바일 375px 화면에서는 기준표의 최소 너비를 유지해 과도한 축소 없이 가로로 확인할 수 있고, 안내 카드는 세로로 자연스럽게 배치됐다. 일시적인 관리자 인증 로딩 상태가 끝난 뒤에도 원비 기준 메뉴와 15개 초기값이 정상적으로 다시 로드됐다.
