# 학교시험·성적 1차 구현

- 관리자 전용 경로: `/school-exams`. 보호자 응답이나 기존 수업일지는 변경하지 않는다.
- 추가 테이블: `exam_schools`, `school_exams`, `school_exam_subjects`, `student_exam_results`. 운영 적용 전에 `drizzle/0027_school_exams.sql`을 검토한다. API는 기존 수학 과정 저장 방식과 같이 누락된 테이블을 `CREATE TABLE IF NOT EXISTS`로 생성한다.
- 시험은 학교·당시 학년·학년도·학기·시험 종류·시험명으로 구분하고 과목별 시험일/만점/학교 평균 출처를 가진다. 비교는 이 시험 과목에 입력된 학생 점수만 사용하며 응시 인원을 항상 보여준다.
- 학생의 현재 학교명은 기존 `students.studentNumber` 값을 입력 제안에만 쓴다. 시험의 학교·학년은 시험 기록에 고정되며 현재 학생 정보와 다르면 관리자가 확인해야 성적을 저장한다.
- 누적 수업 횟수는 **해당 학생·과목의 첫 기록부터 시험 전날까지** 출석한 정식 수업일지 행으로 센다. 수학 반의 `영어 집중 수업`은 영어로 분류한다. 복합 과목 `초등 국사과`처럼 과목별 분리가 불가능하거나 두 과목이 같은 날 `출석+보강×2`인 경우 `확인 필요`로 둔다. 기록이 없으면 `기록 없음`으로 표시하고 0회로 추정하지 않는다. 관리자가 수동 횟수를 입력하면 사유와 함께 표시한다.
- 수학 진도는 성적을 처음 저장할 때 시험일 기준으로 계산해 스냅샷을 남긴다. 기준 데이터가 부족하면 `데이터 부족`이다. 이후 점수만 수정할 때 스냅샷은 유지한다.
- 첫 버전에는 보호자 공개, 마케팅용 외부 공유, 자동 학교 평균 수집을 넣지 않는다. 외부 활용 시 별도의 개인정보·표본 기준 검토가 필요하다.
