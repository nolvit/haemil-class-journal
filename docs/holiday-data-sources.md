# 휴일·휴강 데이터 원천 메모

## 공식 휴일 원천

- 한국천문연구원 특일 정보 Open API는 국경일·공휴일·24절기·잡절 정보를 제공하며, 공공데이터포털에서 자동 승인 방식으로 이용할 수 있다. 엔드포인트는 `B090041/openapi/service/SpcdeInfoService`이다.
- `distbe/holidays`는 한국천문연구원 특일 정보를 바탕으로 공휴일 데이터를 매일 갱신한다. 날짜·명칭·공휴일 여부를 제공하며, 대체공휴일과 선거일을 별도로 반영한다. 연도별 JSON은 `https://holidays.dist.be/{year}.json` 형식이다.
- 운영 앱은 실시간 외부 요청 실패가 출석 화면을 막지 않도록, 검증된 공식 데이터의 연도별 결과를 서버 캐시와 수동 휴강 레코드로 조합해 사용한다. 임시공휴일·추가 선거일처럼 공고 시점이 달라질 수 있는 날짜는 관리자가 휴강일로 즉시 보완할 수 있어야 한다.

## 휴강 이미지 표시 원칙

- 휴강일에 관리자 업로드 이미지가 있으면 `object-fit: cover`로 표시해 날짜 패널의 가로·세로 크기를 빈 공간 없이 채운다.
- 이미지가 없으면 휴강명·기간·안내 문구·아이콘으로 구성한 패널을 표시한다.
- 연속 휴강은 시작일과 종료일을 한 레코드로 저장한다. PC에서는 해당 날짜 폭을 합친 하나의 가로 패널로, 모바일에서는 반복 없이 하나의 휴강 카드로 표시한다.
