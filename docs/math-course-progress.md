# 중등 수학 과정 현황 (HAE-9)

- 관리자 메뉴 `/math-progress`: 전체 활성 수학 수강생 조회, 이름/학년 검색, 초기 기준 일지 확인, 미인식 일지 확인, 학습/평가별 보정 및 자동 복원.
- 보호자: 기존 토큰/가족 권한 확인. 기본 접힘 아코디언. 보정 사유/미인식 원문/초기 기준 원문은 응답에서 제외.
- 현재 학년만 시작하고 진급하면 시작 학년 이후 기록을 누적한다. 현재 중2는 중1 미표시. 관리자 표도 학기별 고정 열 대신 학생별 대상 과정을 표시.
- 단원표: 중1-2 HAE-8 목차 5중단원/22소단원, 중2-2 mathbank `962d6c8` 7중단원/23소단원. 정의되지 않은 학기는 계산/화면 제외. 2~4단계는 자물쇠와 이름 표시. 보호자 화면에 준비 중/미완성 문구 없음.
- 흐름: 모든 소단원 학습 → 고난이도 실력문제 → 모든 소단원 평가 → 예비평가 → 최종평가(1차/2차). 순서대로 화면 표시. 다섯 구간 20%씩. 마지막 구간은 기존 두 최종 평가에 각각 10%. 관리자가 선행 단계를 대기로 보정하면 최종평가 완료여도 단원 전체 완료하지 않음.
- 기본/기본 과정/1단계 헤더 인식. 다음 단계 진입은 앞선 구간 완료의 근거. 소단원 학습 중에는 같은 중단원 평가를 완료 처리하지 않음. 평가 예정/미실시/미완료/평가 대기 줄 제외.
- 사용자 지시로 2026-09-22까지 마지막 비어 있지 않은 확정 수학 일지를 학생별 최초 한 번 `math_progress_baselines`에 저장한다. 최신 기록 인식 실패 시 오래된 다른 기록으로 추정하지 않는다. `[중2-2 / 1단계 / 2-3단원]`은 1단원 전체 완료, 2-1/2-2 학습 완료, 2-3 학습 중, 현재 단원 실력문제/평가 대기.
- 배포 서버 시작 시 전체 수학 수강생에 순차 초기화하며 요약 인원수를 서버 로그에 기록한다. 재시작/동시 요청 시 첫 스냅샷을 덮어쓰지 않는다. 기존 수업일지/출결/원비 레코드를 변경하지 않는다. 추후 신규 학생은 첫 조회 때 빈 기준을 생성하고 새 일지부터 반영.
- 기준일 이전 기록을 반복 파싱하지 않는다. 기준일 이후 일지와 기준일 당일의 새 기록/최신 기록 수정은 반영한다. 복습으로 초기 완료를 하향하지 않는다. 오류 보정은 관리자 수동 상태를 우선 적용한다.
- 자동 계산/수동 보정 분리. 사유/작성 관리자/수정 시각 저장. 자동 복원은 보정 삭제.
- 첫 접근에 테이블 멱등 생성. 조회 시 일지별 SHA256/현재 학년/기준 스냅샷/보정 지문 확인. 변경 없으면 캐시 재사용. 관리자 조회 최대 5명 병렬.
- 현재 점검 브라우저는 관리자 미로그인 상태. 실제 일지 표기 확인 및 적용 인원 검증은 운영 관리자 페이지의 초기 기준 열에서 확인해야 함.

## 2026-09-22 지정 기준 정정

- 현재 중3 및 고등학생은 표기에서 제외. 초기 기준 학년이 중2 이하인 학생이 2027년부터 중3으로 진급하면 기존 진행도를 누적 표시.
- 김화랑: 2026-09-21 / 문민서: 2026-09-22의 수정된 일지 / 전유찬: 2026-09-18. 지정 날짜를 정확히 조회하고 다른 날짜로 대체하지 않음.
- 한재범: 기준일까지 마지막 수학 일지의 중등 학기 표기를 진행도 계산에서 중1-1로 정정. 원본 일지 텍스트는 보존. 새 기준의 학기 목록을 저장해 중1-2가 함께 표기되지 않도록 함.
- 중1-1은 첨부 목차 5중단원·24소단원. 문제은행 추후 적용 목차는 Linear HAE-10에 저장.
- 모든 대상 이름이 활성 수학 수강생 중 정확히 1명인지 확인하고 날짜/단원 인식 검증을 모두 통과해야 트랜잭션으로 네 기준을 반영. `math_progress_correction_history`에 이전/새 기준을 함께 보관. 고유 정정 키로 재실행을 방지하고 수동 보정은 유지.
- 지정 기준보다 늦게 이미 존재하던 9/22 기록을 바로 다시 적용하지 않도록 당일 일지 버전을 저장. 이후 새로 입력하거나 수정한 당일 기록은 정상 반영.
- 새 단원표 추가로 기존 중1-2 학생에게 과거 중1-1 과정이 새로 나타나지 않도록 실제 추적 학기를 사용. 캐시 지문에 단원 키 목록 포함.
