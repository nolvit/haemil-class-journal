# 중등 수학 과정 현황 (HAE-9)

- 관리자 메뉴 `/math-progress`: 전체 활성 수학 수강생 조회, 이름/학년 검색, 미인식 일지 확인, 학습/평가별 보정 및 자동 복원.
- 보호자: 기존 토큰과 가족 학생 권한을 확인한 뒤 기본 접힘 아코디언 제공. 직원 보정 사유와 미인식 원문은 응답에서 제외.
- 기본 과정: 중1-2 HAE-8 기준 목차 5중단원/22소단원, 중2-2 mathbank `962d6c8` curriculum.js 7중단원/23소단원. 다른 학기는 단원표 준비 중이며 계산 제외. 2~4단계는 자물쇠와 이름 표시, 계산 제외.
- 중단원 진행률 = 완료 소단원 학습 비율 50% + 예비/1차 최종/2차 최종 평가 완료 비율 50%. 학기별 중단원 평균 후 두 학기 평균. 소단원 평가는 상세로 별도 표시. 필수 세 평가를 모두 마치면 평가 완료.
- 다음 소단원 기록은 앞선 학습 완료로 판정하되 평가까지 추정하지 않음. 중단원 헤더 아래 평가 진입 기록은 해당 중단원 학습 완료로 판정. 초안 및 한국 날짜 기준 미래 일지 제외. 전체 이력을 합산하므로 복습으로 감소하지 않음. 삭제/정정은 재계산 반영.
- 자동 계산과 수동 보정은 별도 저장. 수동 상태는 자동보다 우선. 보정 사유/작성 관리자/마지막 수정 시각 저장. 자동 복원은 보정 삭제.
- 기존 서버 방식에 맞춰 최초 접근 시 `math_progress_overrides`, `math_progress_cache` 테이블을 멱등 생성. 기존 데이터 수정 없음.
- 조회 시 DB에서 일지별 SHA256 및 보정 지문 확인. 변경 없으면 저장된 집계 재사용, 변경/날짜 전환 시 재계산. 삽입/삭제/이월 등 모든 일지 변경을 포괄하며 반복 전체 파싱을 방지. 관리자 집계는 최대 5명 병렬.
- 운영 DB를 사용하는 브라우저 통합 검수와 배포 후 스키마 생성 확인은 별도 필요.
