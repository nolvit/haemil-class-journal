# 휴강 안내 표시 방식 검토

## 사용자 제공 예시 분석

원본은 2,233×646px의 가로형 표 이미지이며, 좌측부터 우측으로 겹침을 둔 4개 조각으로 확인 중이다. 앞의 두 조각에서 표는 `구분` 열과 월~금 날짜 열로 구성되며, 출석 행 아래에 별도의 높이 큰 `휴강 안내` 행을 둔다. 해당 휴강 행은 화 09.01~수 09.02 두 날짜 폭을 병합해 하나의 배경 이미지와 `학원 휴강 / 추석 / 화 09.01 ~ 수 09.02` 문구를 표시한다. 이미지 아래의 과목 행은 다시 각 날짜 열로 나뉘며 두 휴강 날짜에는 `휴강`을 표기한다.

이 구조는 이미지가 과목 행 자체를 병합하지 않고, **출석 행과 과목 일지 행 사이의 독립 휴강 안내 행**을 날짜 단위로 병합한 방식이다. 따라서 과목 수가 학생별로 다른 현재 동적 표에서도 과목 행 높이와 무관하게 구현 가능하다. 다만 각 주간의 휴강 범위를 테이블의 날짜 열에 맞춰 계산하고, 연속 기간이 주말을 포함할 때 해당 날짜 열을 보여 줄지의 정책을 별도로 정해야 한다.

나머지 두 조각까지 확인한 결과, 이미지 병합 영역은 수 09.02의 오른쪽 경계에서 끝나고 목 09.03·금 09.04·비고 열에는 빈 휴강 안내 셀만 유지된다. 우측 비고 열은 휴강 안내의 병합 범위에 포함되지 않으며 과목 행에서 독립적으로 남는다. 즉 권장 구현은 날짜 열별 `colSpan` 계산으로 휴강 범위에만 패널을 넣고, 범위 밖 열은 빈 셀로 채워 표의 세로선을 안정적으로 유지하는 방식이다.
